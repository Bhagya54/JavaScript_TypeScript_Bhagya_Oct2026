# VS Code Keyboard Shortcuts — macOS (Default)

**Key legend:** `⌘` Cmd · `⇧` Shift · `⌥` Option · `⌃` Control

## General

| Shortcut | Action |
|----------|--------|
| `⇧⌘P` / `F1` | Command Palette |
| `⌘P` | Quick Open / Go to File |
| `⇧⌘N` | New window |
| `⇧⌘W` | Close window |
| `⌘,` | Settings |
| `⌘K ⌘S` | Keyboard Shortcuts |

## Basic Editing

| Shortcut | Action |
|----------|--------|
| `⌘X` | Cut line (no selection) |
| `⌘C` | Copy line (no selection) |
| `⌥↑` / `⌥↓` | Move line up / down |
| `⇧⌥↑` / `⇧⌥↓` | Copy line up / down |
| `⇧⌘K` | Delete line |
| `⌘Enter` | Insert line below |
| `⇧⌘Enter` | Insert line above |
| `⇧⌘\` | Jump to matching bracket |
| `⌘]` / `⌘[` | Indent / outdent line |
| `⌘←` / `⌘→` | Go to start / end of line |
| `⌘↑` / `⌘↓` | Go to start / end of file |
| `⌘/` | Toggle line comment |
| `⇧⌥A` | Toggle block comment |
| `⌥Z` | Toggle word wrap |
| `⌥⌘[` / `⌥⌘]` | Fold / unfold region |
| `⌘Z` / `⇧⌘Z` | Undo / redo |
